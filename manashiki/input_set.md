## 1. 要約

YouTubeの企画・台本・編集を全部Claude Codeで回して毎日投稿している、という実践報告が土台。その上で、SNSは「中身（人の心を掴むこと）は全プラットフォーム共通、違うのは見せ方だけ」という結論で、プラットフォーム別の見せ方の要点を並べた動画。

- YouTube／Instagram共通で最初に効くのはファーストインパクト（YouTubeならサムネイル）。
- プラットフォームごとに「どの見せ方が評価されるか」が違う。特にInstagramはアルゴリズムとデザイン統一感の比重が大きい。
- 投稿を何本か出すと傾向が掴める（分析力より蓄積）。出す前の推敲より、出してからの改善を前提にする。

## 2. ノウハウ（手順・考え方として転用できる部分）

### YouTube
1. **サムネイルとタイトルで「答え合わせ」ができる企画にする**：サムネイルで提示した問い（例：「Claude Codeで月100万稼ぐ方法10選」）に、動画本編がそのまま答える構成にする。タイトル・サムネと中身がずれた動画（例：サムネは「noteの稼ぎ方」なのに中身はアフィリエイトのやり方）は伸びない、というのが話者の経験則。
2. **サムネイルはデザインセンスより先に「初級のインパクト」**：文字は大きく、言葉だけで内容が入ってくること。配色や装飾の上手さより、「どの言葉を使えばインパクトが出るか」を先に考える。
3. **数字で中身を予告する**：「10選」のように本編で扱う個数をタイトル側に出すと、視聴者が「この話がされる」と事前に分かる。
4. **YouTubeは遅れて伸びることがある**：公開3日後・1週間後・1か月後に伸び始めることがあるので、公開直後の数字で切らない（Xは基本「今日・明日」が勝負、という対比）。

### Instagram（ショート動画）
1. **ジャンル認知が要る**：「このアカウントは何の発信か」を、キャプションやサムネイルだけでなく、動画の中身・喋り方（口調）まで含めてアルゴリズムと視聴者に伝える。
2. **視聴者の関心との一致が評価を左右する**：普段からそのジャンルを見ている人に届かないと評価が上がりにくい、という話者の理解。
3. **発見の主戦場はリールタブで、1枠ずつしか出てこない**：だから最初の段階でアルゴリズムを考えた作りにする比重が大きい。
4. **デザインの統一感が最も重要なのはInstagram**：プロフィール・フィード・リールでトーンと色を揃える。

### X／Threads
- アルゴリズムはInstagramほど気にしなくてよく、「心に刺さるか」が中心、という話者の整理。
- Xも本数を出す中で傾向を掴む。公開後でも改善（直し）してよい前提で出す。

### 共通の制作姿勢
- プラットフォームごとに言葉遣い（見せ方）は変えるが、狙う「相手がどう感じるか」は共通。
- 企画・台本・編集をAI（Claude Code）に寄せて、毎日投稿できる軽さを作るのが話者の運用形。
