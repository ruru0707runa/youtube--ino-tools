## 2. 各特典の要点

### 特典1 ライティング10箇条（台本の文章チェック）
初心者の台本ミスを10項目に整理したもの。前半3つは日本語の基礎、後半7つは短尺動画特有の工夫という位置づけ。

1. 助詞（てにをは）を正しく使う — 助詞1つで強調点と印象が変わる
2. 主語と述語を一致させる — 長文は主語・述語に印を付けてねじれを確認
3. 一文を短くする — 1文に伝えることは1つだけ
4. 冒頭でテーマを明確に伝える — 初見が前提。冒頭に自己紹介と結論を置く
5. キャラクターを明確にする — 話し方・語尾・行動まで初期設計と統一
6. 情景が浮かぶ言葉を使う — 抽象表現を具体的な描写に置き換える
7. 視聴者を置いてけぼりにしない — 出来事のつながりと理由を省略しない
8. 並列する言葉をまとめる — 繰り返しは共通項でくくって短くする
9. 語尾を統一する — 文末の調子を混在させない。続く場合は名詞止め等でリズム調整
10. 感情を伝える箇所でのみ強い言葉を使う — 1〜9が土台の上級編。要所だけ

- 見直し方法: 書いた直後でなく時間を置く、場所を変える、他者に読んでもらう、AIに違和感を聞く。
- 最終基準は3点: 視聴者目線で整理できているか／感情に訴える言葉があるか／キャラの個性が入っているか。

### 特典2 自己分析方法（初期設計の材料集め）
- プラス要素とマイナス要素を、取捨選択せずまず全て書き出す。性格の癖、環境、体型・健康・経済面の悩みなどコンプレックスも含める。
- 弱みは絶対的な欠点でなく「ゴールに対して不利になるもの」で判定する。一般には長所でも、目的に対して続けにくさ・苦手さに転じれば弱みとして使える。
- 自分で分からない場合は他者に聞く。他人と比べて羨ましい点・劣ると感じる点が、自分の欠けている部分の手がかりになる。

### 特典3 初期設計攻略法（ゴールとギャップ）
- 手順: ①大きなゴールを1つ決める（到達点が一目で分かる形）→ ②スタート地点を意図的に低く見せ、ゴールまでの幅と「達成できるか分からない」不確実性を作る → ③過去の実績・権威性は初期は伏せる（できそうな人には応援が集まらないという判断）→ ④ギャップはスタート→ゴールの軸に関係する要素だけで作る。
- ギャップの採否チェック: その要素を足すと「本当に達成できるのか」という疑問が増えるなら採用、増えないなら不採用。関係ない属性（軸と無関係な体型・身長など）はギャップにならない。やり過ぎ（裏に大人がいると疑われるような設定）は不採用。
- 組み合わせの狙いは「自分のキャラ × ジャンル × 状態 × ゴールへのアプローチ」で他にない形にすること。過程そのものを連載化し、最終結果だけを見せない。

### 特典4 最強の「冒頭」の作り方（物語設計）
- 自己紹介を冒頭の固定資産にする: 同じ軸の上にギャップを入れた自己紹介を目安30〜40文字で作り、認知が取れるまで毎回冒頭に入れる。作り方は単語を大量に出し、地域・規模・状態・役割などを1語ずつ差し替えて検証する入れ替え作業。
- ネタ出し: 今後起きること・直すべきことを全て箇条書きし、完成後ではなく完成までの過程をコンテンツ化する。各課題に「どういう一言なら指が止まるか」を考える。
- 初投稿は初期設計を紹介する予告編型にする。できないこと、協力者・意見の募集も明示し、視聴者と一緒に作る形を伝える。
- 冒頭の一言はネガティブな感情（恐怖・不安・怒り）に寄せると止まりやすい。ただし釣りっぱなしは禁止で、後半で必ず伏線回収し、誰も損しない・好感度が上がる着地にする。
- 物語の型（1話完結）: 起＝ネガティブな一言＋自己紹介／承＝問題と経緯／転＝伏線回収／結＝必ずハッピーエンド（バッドエンドはいいね・共有されにくいという理由）。
- 心理学用語、バズワード、プレゼント企画、トレンド音源、細かいカット割り等の小手先より、コンテンツ自体を考える時間を優先すると明言。
- コメントを増やす方法は「視聴者にアイデアをもらい、調べる・実践する過程を見せる」。ただし素人ポジションだから成立する手法で、専門家ポジションでは使いにくいと留保。

### 特典5 海外動画リサーチ術（ネタの輸入と比較）
- 制作ロードマップの例（話者の運用）: リサーチ約2時間＋競合分析約2時間＋視聴者のアクション想定約5分 → 台本 → 撮影 → 編集 → チェック。夜に台本まで、翌日の明るい時間に撮影、という日次サイクル。
- 前提: 自分の「面白い」という感覚を最初は信用しない。国内のおすすめ欄は皆が見て飽きているため、海外・他プラットフォームで既に伸びたネタを輸入する。
- 海外リサーチの手順: 普段用とは別の作りたてアカウントを海外専用に育て、英語キーワードで検索し、海外アカウントをフォローし続けておすすめ自体を海外寄りにする。日本で既に知られているか日本語検索で確認し、需要の裏付け（過去に伸びた日本語投稿がある等）があれば採用。日本人の感覚に合わないものは驚きがあっても採用しない。
- ソースの使い分け: TikTok＝Instagramのおすすめにないバズネタ探し。Q&Aサイト等＝バズ探しではなく、ペルソナの困りごと・欲しい解決策探し。
- 競合分析「連想ゲーム」: 同じネタの「伸びた投稿」と「伸びない投稿」を両方集め、冒頭にある要素だけを書き出して差を抜く。商品名だけで検索せず、その商品の本当の売りで連想して検索し直す（切り口自体が差別化になる）。
- トラブルシーンの設計（5段階）: ①有益情報を決める → ②それが解決する問題を洗い出し、同類キーワード検索で「自分だけの悩みでない」裏付けを取る → ③問題が起きると具体的に何に困るかを考える → ④関連ワードを連想して投稿をリサーチ → ⑤冒頭に使うシーンを決める（原則は共感されるトラブル場面）。
- 線引き: 使うのは日常の軽いトラブルまで。子供を危険に晒す・そう見える場面は、バズっても炎上とフォロワー転換率の悪化を招くため避ける。トラブル冒頭は投稿全体の一部に抑える。

### 特典6 アクションをさせる台本テク（保存・コメントの設計）
※この動画の字幕は制作フロー全体のステップ3から始まる。ステップ1〜2は特典5（リサーチ／競合分析）が担う前編にあたる。
- 最初に決めるのは狙うアクション: 投稿ごとに「感情型＝コメント狙い」か「行動型＝保存狙い」かを決めてから台本を書く。具体的なコメント文まで決めなくてよく、見終わった後に残したい感情を先に決める。
- 台本は3段構成: ①冒頭の一言 → ②困りごと → ③解決の手法。バズを狙う回では自分の感想を削り、手法で終わらせる。
- 保存されやすくするため、手順はステップ数や秒数など数字で言える形に寄せる。
- コメントの入口: 初見の視聴者は入口がないとコメントできない前提で、あえてツッコミどころになる小物・背景・見た目の要素を入れる。
- 冒頭の作り方は2通り: ①自分の普段の感情・口癖をそのまま言葉にする ②伸びた動画（目安として100万再生級）に共通する冒頭ワードを複数書き出して組み合わせる。
- 映像のルール: 属人性を消す回は顔を出さず手元中心。映像で分かる動作はテロップにせず、映像だけでは分からない情報だけを文字にする。CTA部分を除き1カットは原則2秒以内、速すぎる切り替えは疲れるため避ける。
- 参考アカウントの冒頭ワードを新作のたびにノートに書き出し、季節・イベント需要への当て方まで日常的に観察する。リサーチは制作時だけでなく日常業務という位置づけ。
- 演出は「実際に起こり得る範囲」が上限。過剰演出は嘘っぽさへの反発を招く。
- 撮影は自然光のみ（日中、部屋の電気を消し、最も明るい窓際＋レースカーテン）。アフレコは距離と姿勢を毎回固定し、抑揚は録音で弱まる前提で大げさめに付ける。

### 特典7 動画編集5STEP
1. ナレーションの無音部分を詰めるカット編集（映像ではなく音声から始める）
2. 撮影素材を選定する
3. 素材をカットしてつなぐ
4. テロップとデザインを編集する
5. BGMと効果音を付ける

- カットごとに明るさを統一する。ナレーション同士は言葉の終わりと次の頭を少し重ねて途切れ感をなくす。
- BGMはトレンドより適合優先。流行曲に頼らず、投稿の雰囲気とアカウントの世界観に合う曲を選ぶ。
- 最終チェックは2点: ①1シーンにつきメッセージが1つに絞れているか、映像とテロップにズレがないか ②台本と映像素材の感情が合っているか。
- 完成してすぐ出さず、一晩寝かせて翌日にリセットした目で見返してから投稿するルーティン。
- 初心者の練習法: 憧れる発信者の投稿を画角・テンポ・声の速度まで真似る完コピ練習。ただし練習作は公開しないことが条件。
- 結論として、編集技術を上げてもバズには直結せず、差がつくのは日々のリサーチ量と冒頭設計だと締める。

### 特典8 PREP法（資料PDF、全8ページをテキスト抽出して確認）
台本構成は「9割が構成」という前提で、PREP法をリール向けに読み替えた資料。

- **P（結論）**: 冒頭5秒。動画の中で最も面白い見どころをダイジェストで先見せし、「自分に関係がある」と思わせる。意外性・常識破壊・好奇心を刺激する言葉を選び、視聴者の実際の声から「思わず反応する言葉」を借りる。
- **R（理由）**: 多くの視聴者が抱える悩み・あるあるを言語化し、視聴者を物語の当事者にする。ペルソナは「過去の自分」に設定し、当時のリアルな悩みを具体的な情景で描く。
- **E（具体例）**: 悩みへの解決策を映像で見せる。スペックの羅列ではなく「使うとどう生活が変わるか」を見せ、映像の引きと寄りを使い分ける。
- **P（結論）**: 全体の価値を要約し、冒頭のツカミとリンクさせて伏線を回収する。最も重要なベネフィットを、簡潔で覚えやすいフレーズで言い切る。
- 実例3本（防災バッグ／収納ラック／ケーブルボックス、いずれも商品紹介リール）がP→R→E→Pの割り当て付きで示される。
- TTP（徹底的にパクる）への線引き: バズ目的の丸パクリは「またこれか」と見抜かれて離脱されるため不可。型を体に染み込ませる練習としてのみ有効。バズ動画から面白いと感じた要素だけを抽出し、自分の体験・視点と掛けてオリジナルに昇華させるのが、あるあるネタの正しい探し方とされる。

### 特典9 撮影法（カットのつなぎ方）
- 総論: 映像は強いカットの寄せ集めではなく、つなぎ方で魅せる。見せ場の前に過程・予兆のカットを置いて期待感を作ってから出す。
- 引きと寄り: 引き＝場所・全体像・周囲との関係（状況説明）、寄り＝表情・質感・手元（注目点）。ズームで寄せるのではなく、引きと寄りを別カットで撮って切り替える。寄りだけで続けず引きを挟んでリズムを変える。
- 移動カット: 場所が変わる境目に、移動している最中のカットを1つ挟み、いきなり別場所へ飛ばない。扉を開ける、蓋を開ける、持ち上げる、組み立てる等の「ワンアクション」も省略せず細かく入れる。
- カメラワーク: カメラ自体は動かさず固定し（手ブレ回避）、代わりに被写体や手を動かして画面内に動きを作る。
- 機材・解像度・照明などの具体的な数値設定の提示は本編にない。

### 特典10 伝説の台本の作り方（本編5工程＋冒頭7工程、長尺86分）
実例アカウントの台本2本（起承転結型とPREP法型）を分解しながら手順化した講義。後半は編集実演。

**台本が下手な人の特徴（前提として直す3点）**
1. キャラクター設定が台本から伝わらない
2. 情景が想像できない抽象的な言葉になっている
3. 日本語の文法・助詞の誤りがある

**本編作成 5ステップ（話す順には作らない）**
1. 伝えたい情報を全て書き出す（関係なさそうな話も一旦メモに残す。「なぜ」を繰り返して理由・背景・数字を引き出す）
2. 5W1Hで整理し、使う情報と今回使わない情報（テーマが広がりすぎるものは別回へ）を選別する
3. 構成の型に当てはめる（起承転結かPREP法か）
4. 各パートごとに山場を作る（転まで待たず、冒頭寄りから小さな山を連続させる。下記の4要素のいずれかを各パートに入れる）
5. キャラに合う言葉遣いに直す（動詞1つ、言い切り方1つまでキャラ像に合わせる）

**山場を作る4要素**: 感情が表れる言葉・行動／共感を呼ぶ強い思い・本音／コールドリーディング（視聴者が内心思っていることを先に言語化する）／新発見・驚き。

**冒頭タイトル作成 7ステップ（本編の後に作る）**
1. 内容に関連するキーワード・言葉を大量に書き出す
2. 最も伝えたいテーマに合うキーワードを1つ選ぶ（多くの人が経験し共感しやすい身近な題材を優先）
3. そのキーワードをSNSで検索し、伸びている動画と切り口を見る
4. 検索結果への反応（不満・驚きなど世論の方向）を確認する
5. 他動画の冒頭のキャッチコピーを集めて比較する
6. 言葉を強める（「つまりどうなるか」「なぜ」の連想を繰り返し、一旦過剰な表現まで出し切ってから、動画に合う強さを選ぶ。長さは短く保つ）
7. 内容とキャラクターに合っているかを最終チェックする（根拠を示せない誇張、キャラに合わない攻撃的な言葉は採用しない）

**次回予告の扱い**: メリットは期待感と継続視聴、デメリットは次回内容が固定されること。入れる場合は手を抜かず、視聴維持データで予告部分の離脱を確認し、落ちていれば要否自体を見直す。

**編集への接続（実演部分）**: ナレーションのカットから始めて尺を先に決める。素材はナレーションと内容を一致させ、文の区切りごとに細かく切り替える（目安2秒以下）。テロップは基本1行、長くても2行。強調部だけ色・書体を変える。撮れない・分かりにくい説明はアニメーションや図で補い、静止画も必ず動かす。

## 3. 実務アウトプット（ino向け転用）

### 3-1. ren台本チェックにそのまま足せるもの（既存の品質ゲートへの追加分）
既存ルール（フック3案採点、0〜2秒で部位名指し／常識破壊、答え合わせ、保存の理由、AI.mdブリーフの手順照合）はそのまま土台にする。今回足す価値があるのは次の4点だけ。

1. **特典1の10項目を台本の最終チェック表にする** — 特に ren で効くのは「一文一義」「語尾の統一」「情景が浮かぶ言葉」「つながりの省略なし」。TTSで読ませる台本ほど助詞のねじれと文末の混在が耳で目立つため、制作前の文章チェックとして相性がよい。
2. **狙うアクションを台本の冒頭に書く（特典6）** — 1本ごとに「保存狙い／コメント狙い」を先に決め、台本ファイルの先頭に明記する。renのA（診察室）／B（保存用チェックリスト）／C（参加型診断）のシリーズ分けとそのまま対応する。
3. **本編→冒頭の順を固定する（特典10）** — フックは本編が固まってから、キーワード書き出し→同テーマの伸びた投稿の冒頭比較→世論の方向確認、を経て作る。今の「フック3案を採点して弱い案を落とす」工程の前段として組み込める。
4. **山場4要素を中盤の離脱防止チェックにする（特典10）** — 各パートに「感情／共感する本音／視聴者の内心の先回り／新発見」のどれか1つが入っているかを見る。renの離脱秒を特定する分析と組み合わせる用途。

### 3-2. カット設計への転用（特典9）
- AI生成でも「引き＝全体の様子／寄り＝部位と手元」「見せ場の前に過程を置く」「動作を省略しない」はシーン設計としてそのまま使える。renの「全体のBefore → 部位をつまむ寄り → After確認」の流れはこの型と一致している。
- ただし実写前提の部分（固定撮影で手ブレ回避、ズームの使い方、自然光の撮り方）は生成では対象が違う。細かく刻みすぎると犬の模様・部屋の一貫性が崩れるため、カット数ではなく意図だけを借りる。

### 3-3. 物語型への転用（特典3・4）
- 「ゴール先決め→スタートを低く→軸の上だけでギャップ→過程を連載化」は、新規シリーズやThreads連載「よるの診察室」の設計論として使える。既に設計済みのren初期設計をやり直す理由にはならない。
- 自己紹介を毎回冒頭に入れる手法は、リールのフック先行型とは競合する。使うならプロフィール／固定投稿／連載の導入回に限定するのが現実的。

### 3-4. shibaへの転用
- yuuki実験の結論（伸びるのは犬の日常・あるある、ノウハウ単体は伸びない）と、特典5の「トラブルシーンは日常の軽いものまで」「共感できる困りごとから始める」は方向が一致する。shibaの冒頭は、困りごと・あるある場面から入る設計が数字とも教材とも合う。
- 特典5の「伸びた投稿と伸びない投稿の冒頭だけを比べて差を抜く」は、shiba／ren共通のリサーチ手順として採用できる。ただし実施方法は既存の安全ルール（2026-11-17採用）に従い、Instagramをブラウザで開くリサーチはしない。公式連携（コネクタ／CLI）の範囲で行う。

## 4. 採用しないもの・注意が必要なもの

- **言葉を限界まで強める手法（特典10ステップ6、特典4のネガティブ釣り）**: 連想で誇張を最大化してから戻す作り方と、恐怖・不安で止める冒頭は、健康テーマでは効能の断定・誇張に直結する。renではAI.mdブリーフの言い換え表（「消える・治る・若返る」は使わない等）が優先し、この手法は採用しない。強さの上限は「部位名指し／常識破壊」まで。
- **過剰演出の事例（特典6）**: 実際に起こり得る範囲、という話者自身の上限設定は参考になるが、演出で現象を作る発想自体は犬の健康コンテンツには持ち込まない。
- **実写前提の機材・収録論（特典6・9）**: 照明、iPhone機種、アフレコの録音環境などは、TTS＋AI生成のren制作には直接使えない。
- **「一晩寝かせる」ルーティン（特典7）**: 考え方（リセットした目で最終チェック）は有効だが、renは1日1本・20:00公開の予約運用のため、寝かせる工程は「予約前の最終チェックを別タイミングで1回挟む」形に読み替える。
- **完コピ練習・TTP（特典7・8）**: いずれも「公開しない練習としてのみ」という条件付きでの推奨であり、公開物への流用は話者側も否定している。型の分解（既存のリール解剖）とは別物として扱う。
